Pretrained Checkpoint

microsoft/trocr-base-printed — pretrained on 684M text line images (synthetic + real). We fine-tune only on SROIE receipt data to adapt to the receipt domain.

Why TrOCR?

End-to-end Transformer (no CNN backbone, no CTC decoder). Both encoder and decoder are Transformers. Strong SOTA results on IAM and SROIE. Well-supported via HuggingFace — easy to fine-tune and deploy.

Data Preprocessing Pipeline

Crop individual text line images from receipts using bounding box annotations → Resize to 384×384 → Normalize with ViT preprocessing → tokenize ground truth with TrOCR tokenizer → split 80/10/10 train/val/test.

07 Evaluation Metrics
CER — Character Error Rate

Primary metric. Measures edit distance at character level normalized by length. Lower is better. Particularly important for receipts where digit errors (e.g. price 12.50 → 12.80) are costly.

WER — Word Error Rate

Secondary metric. Same principle at word level. Useful for evaluating readability of full receipt lines (store names, item descriptions).

Qualitative Analysis

Visual comparison of predicted vs ground truth on 10 sample receipts. Identify failure cases: low contrast, cursive fonts, stamps, damaged areas. Important for the report discussion section.
